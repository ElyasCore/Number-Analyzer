## Number Analyzer

A Java console application that analyzes five user-entered numbers and calculates several basic statistics and classifications.

The project focuses on using loops, counters, accumulators, the modulo operator, and conditional logic to process multiple inputs and maintain results while the program runs.

### Features

* Enter five numbers
* Calculate the total sum
* Calculate the average
* Find the largest number
* Find the smallest number
* Count even and odd numbers
* Count positive, negative, and zero values
* Display the analysis results

### Concepts Practiced

`Scanner` · `for` Loop · Variables · Counters · Accumulators · `if/else` · Modulo Operator `%` · Comparisons · Arithmetic Operations · State Tracking

Built as part of my Java learning journey to practice processing multiple inputs and maintaining values such as sums, counters, and minimum/maximum numbers.
